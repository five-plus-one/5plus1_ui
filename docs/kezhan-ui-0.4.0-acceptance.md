## 设计与交互调整

- 使用既有语义色、产品主题与密度规范；品牌识别色保持 #FD8B07。实心操作使用成对的操作色与文字色。
- 行内公式保留原行布局，编辑卡片在段落下方展开；收起保持 220ms 过渡及快速重开清理。段落正文及其后的文字参与同一收起生命周期。
- 卡片类型可搜索，新增音频、历史地图、学习动画与附件设置。视频、图片等属性可编辑；指令属性与正文往返保留，连续转换不累积空行。
- 原生日期、时间、颜色与选择弹窗采用设计系统控件；表单提交所需的隐藏选择元素保留，不呈现浏览器菜单。
- 展开内容采用尺寸过渡；输入框自动增长、分段滑块、文件夹、卡片与浮层采用短时动效，并响应减少动态效果设置。
- 资源管理支持空白区与条目菜单；拖动拒绝把文件夹移入自身后代。窄屏任务栏自动收纳，管理明细在窄容器中逐条展示。
- 异步操作具有重复提交保护、错误反馈及恢复入口；搜索和授权源解析可取消，旧请求不会覆盖新内容。

1. **15 个测试文件、113 项测试通过**。覆盖受控接口、请求乱序、错误与重试、权限展示、Yjs 共享文档、编辑序列化、快捷键、播放器、菜单、公式动画生命周期、大目录、多选与框选等。
2. **188 个示例**分别对照源码接口及独立安装包类型声明编译通过。
3. 设计站、组件包和类型声明构建通过；独立消费者安装 `fiveplusone-ui-0.4.0.tgz` 后检查公开导出与类型，运行时可读取 225 个公开导出。
4. 浏览器检查覆盖全目录的浅色移动端、深色桌面；既有及新增条目另有浅色桌面、深色移动端记录。最终补验未出现外层横向溢出或可见的原生日期、颜色、选择及媒体控件。
5. 专项操作包括千项目录列表/网格、窗口收纳、版本切换、邀请反馈、关系图、卡片搜索和类型切换、音频地址编辑结果，以及公式展开时同行文字位置。

浏览器尺寸检查证明容器布局和原生控件呈现结果；它不等于每个入口所有状态的像素验收。测试及浏览器证据位于 `tests/` 与本地 `.work/acceptance-20261020/`。后者包含截图和测量记录，不随发布包公开。

## 课栈接入边界

课栈应用源码本轮仅读取；其既有改动保留。组件库已经提供可复用展示层与受控接口，**课栈实际替换和生产服务联调仍需另行执行**。

- 账户请求、权限判定、邀请发送、购买、积分记账和保存事务由课栈负责。
- Office 转换、授权资源、上传、跨设备协作连接、持久化及课堂进度由课栈接入真实服务。演示不承担这些生产服务。
- 68 个学科实验保留原有计算与专用渲染引擎，复用 CanvasWorkbench、参数控件、窗口和录制视图。对应表中的“视图接口已提供”不表示这些源文件的参数界面已经完成替换。
- 分子、函数、HTML/SVG 与学科内容通过渲染插槽接入；组件库不执行来源不明的页面脚本。实际授权规则由宿主控制。
- 鼠标框选和宽度检查已验证；完整真实触屏、跨设备网络协作及所有学科内容的端到端任务仍应在课栈接入时验收。

本记录用于界定可复用组件交付及其证据。它不将通用工作台外壳、文件映射或演示数量等同于整个课栈前端重构完成。
