# 五加一设计规范

## 目标

让学习、阅读、创造与协作拥有一致的操作习惯。信息层级、内容可读性和操作确定性优先；品牌通过色彩、排版、留白与少量几何图形体现。参考 Material Design 的语义色、状态、导航和可访问性原则，以及 1037solo 与 fiveplus.one 的品牌表达。来源见调研文档。

## 视觉基础

统一使用 `--fp-*` 语义变量。背景为 `--fp-bg`，内容面为 `--fp-surface`，次级面为 `--fp-surface-muted`；正文为 `--fp-ink`，辅助正文为 `--fp-muted`，边界为 `--fp-line`。主操作使用 `--fp-primary` 与 `--fp-on-primary`；品牌橙 `--fp-brand` 用于识别与少量强调。成功、提醒、错误同时提供文字或图标提示。

品牌主色固定为 **#FD8B07**，通过 `--fp-brand` 承载，不随产品切换。默认五加一主题使用品牌橙；产品以 `data-product="kezhan"`（课栈蓝 #1A73E8）、`marker`（批改助手绿 #13795B）、`onepass`（账号紫 #7252C7）独立设置操作主题。产品配色为当前设计方案，统一维护于 `src/lib/themes.ts`，构建自动生成对应 CSS。可从组件包导入 `productThemes` 与 `ProductTheme`。

根元素设置 `data-theme="dark"` 切换深色；默认 `data-product="brand"`。品牌识别色为 #FD8B07；实心操作使用成对的 --fp-action 与 --fp-on-action，浅色为 #B85E00 / #FFFFFF，深色为 #FFB65C / #492600。文字链接与焦点使用主题对应的强调色。产品主题使用各自的对比文字、浅色容器与深色模式变量。成功、提醒、错误语义独立于产品主题。弹层挂载到 body，宿主应在根元素设置主题。

系统字体优先，中文使用苹方或微软雅黑。阅读正文建议 16px、行高 1.7–1.9，行长约 36–46 个汉字。关键内容避免使用浅色小字。间距以 4px 为基础，常用 8、12、16、24、32px。控件圆角 6px、卡片 8px、大容器 12px；阴影主要表达浮层层级。

## 页面与交互

宽屏采用稳定侧栏、页面标题和内容区；窄屏导航进入抽屉，表单与业务分栏顺序堆叠，宽文档在预览区域内部滚动。每个任务保持明确的主操作。品牌页可用大标题和几何构图，工作区保持安静的背景，阅读模式优先保证资料与笔记面积。

组件应覆盖默认、悬停、聚焦、按下、禁用、加载和错误。已知比例用进度条，未知等待用加载指示；空状态说明内容与下一步；错误提供恢复入口。字段附近解释输入错误并保留已填写内容，提交期间阻止重复提交。不可恢复操作明确说明对象，可恢复操作优先提供撤销。

## 可访问性与文案

交互支持可见键盘焦点，图标按钮有名称，表单有标签，错误用文字表达。触摸环境主要操作目标至少 44px，尊重减少动态效果偏好。弹窗使用原生 dialog；文件树支持方向键和 Home/End，标签页支持左右方向键。新增组件检查键盘路径、缩放、长文案、空数据和深浅主题；宿主仍需验收完整任务的可访问性。

界面说明当前任务、结果、问题和下一步。AI 记录显示“正在阅读资料”“整理章节”等行动，内部工具、参数、存储字段、调试日志留在开发诊断中。生成结果提供来源、进度和应用入口，有不确定性时说明具体缺失信息。

## 扩展原则

先复用语义变量与组件，再添加产品模式。新增组件提供类型、受控状态、键盘行为、加载与错误状态、交互示例和接入说明。复杂业务服务通过参数与回调注入；权限和持久化由宿主负责。

## 密度与动态反馈

默认采用舒适密度：主要控件最小高度 44px，表单标签与控件间距 8px，卡片内边距 24px，纵向布局默认间距 24px，横向控件组默认间距 12px。表格行使用 16px 垂直内边距，文件树默认行高至少 44px。需要高密度工作区时，在容器设置 `data-density="compact"`；内容阅读和主要表单优先保持默认密度。

共享动态变量：`--fp-motion: 200ms`、`--fp-motion-enter: 260ms`、`--fp-ease: cubic-bezier(.2,0,0,1)`。按钮按下使用 1px 位移；标签指示条连续滑动；菜单与弹窗以轻微位移和透明度过渡。公式使用正文内展开卡片；动态内容通过 AnimatedSize 测量真实高度，展开、收起、文件加载及预览模式切换连续过渡。原生 dialog 的显示与遮罩离场使用离散属性过渡；折叠区域使用网格行高插值，连续点击时平滑反转，收起内容退出键盘路径。遵循 prefers-reduced-motion。

品牌识别色为 #FD8B07。实心操作使用 `--fp-action` / `--fp-on-action` 配对；品牌浅色主题为 #B85E00 与白色，深色主题为 #FFB65C 与 #492600。其他产品由各自主题生成配对色。单选框使用内容面作为底色，操作色绘制外圈和圆点；禁用按钮使用中性底色与弱化文字。日期、时间、颜色及候选选择采用统一主题弹层，支持手动输入、键盘选择和关闭恢复焦点。

筛选标签采用轻量尺寸：桌面高度 32px、字号 13px、横向内边距 12px；徽标保持 11px 字号。触摸设备扩大标签点击区域。宽松布局通过分组间距表达，不统一放大轻量控件。

## 正文与字段分组

Markdown 阅读、富文本编辑和协作编辑共用正文节奏：16px 正文、1.9 行高、段落间隔 16px、章节前距 32px、内容块前后间隔 24px。列表相邻项间隔 8px，嵌套列表保留较紧凑的层级。表格单元格使用 12px / 16px 内边距。首尾元素消除多余的外边距，正文不依靠空段落制造留白。

设置面板字段组间隔 24px、标签与控件间隔 8px，底部操作区与内容间隔 24px。默认内容面板内边距为桌面 24px、窄屏 20px。标签和工具栏保持轻量尺寸。

浮动窗口标题位于左侧，附加操作和窗口控制位于右侧，关闭按钮为最右侧操作。标题文本省略时保留完整提示，按钮不触发窗口拖动；窗口边界约束使全部控制持续可达。
