## 交付范围

## 设计与交互

沿用品牌色 `#FD8B07` 和产品独立配色。设置表单使用统一的字段、段落间距、反馈及操作区；窄屏自动改为单列。外观预览实际应用到视图，浮层继承触发区域的主题和文字颜色。

Markdown 编辑器保留 `/` 插入、可搜索卡片类型、展开卡片、Mermaid、公式矩阵、表格、块拖动和协作。卡片显示一份标题，阅读与编辑切换保持内容。公式关闭保留约 220 ms 的收起过程；实际浏览器复核中，行内公式前后处于同一段落，展开段落高度约 234.41 px，收起后约 30.40 px，后续文字节点保持不变。

高度变化使用 `AnimatedSize` 或 `CollapseTransition` 跟随内容测量；设置切换指示块约 180 ms，内容高度变化约 240 ms。减少动态效果时取消相应过渡。浮窗关闭按钮位于标题栏右上角。文件、目录、资源和编辑器使用各自的上下文操作入口。

视频播放器提供空格/K 播放暂停、J/L 跳转、方向键进度与音量、M 静音、F 全屏、数字定位、Home/End 及逐帧操作；输入区域和中文输入过程保留原有键盘行为。

## 接入边界

本次交付完成组件库的视图、编辑交互和宿主调用契约。课栈生产源文件当前引用 `@fiveplusone/ui` 的数量为 0，生产应用整体迁移尚需在接入阶段验证。

鉴权、实际账户权限、数据持久化、发布与恢复服务、计费、流式对话、Office 转换、授权媒体、跨设备协作服务和分子专用运行时继续由课栈提供。浏览器示例使用演示数据，操作回调展示实际触发结果；接口成功必须以宿主服务确认作为依据。

接入方式和异步错误契约见 [工作区接口](kezhan-workspace-contracts.md)、[迁移指南](kezhan-migration-guide.md)。生产接入验收应使用真实授权、课程资料和多人会话，并覆盖历史笔记兼容、保存恢复与服务异常。

## 发布

设计站以网关 1Panel 静态网站发布到 [ui.five-plus-one.com](https://ui.five-plus-one.com)，使用独立版本目录与原子切换。发布编号、线上文件摘要验证及恢复方式见 [部署记录](deployment.md)。组件包随私有 GitHub 仓库交付，可在本地执行 `npm pack` 生成安装包。
