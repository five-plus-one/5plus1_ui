样式边界

嵌入其他网站时，按钮与输入控件保持组件自己的尺寸和外观。

自适应操作栏

调整容器宽度，常用操作按原顺序展开，其余收进“更多”。

即时提示

鼠标进入或键盘聚焦即可查看操作说明。触屏保留清晰标签。

接入示例

const roots = ['#my-panel'];
FivePlusOneEmbeddedUI.installBoundary(document, roots);
const disposeTips = FivePlusOneEmbeddedUI.installTooltips(document, roots);
const toolbar = FivePlusOneEmbeddedUI.enhanceToolbar(bar, {
  onAction: handleToolbarClick,
});
// 关闭时释放组件。
toolbar.destroy();
disposeTips();
